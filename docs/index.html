Is there an app to study for the journeyman or master electrician exam?

Yes. Electrician Exam Practice 2026 is an iPhone and iPad study app for apprentice, journeyman, master and contractor candidates working from 2023 NEC values. It drills code navigation and the calculations that fail people, and it names what it does not cover.

Is the electrician exam open book, and how do I find answers faster?

Many electrician exams let you bring the code book, but they are timed, so slow lookups cost you questions you never reach. The Code Basics room trains you to read a scenario and name the article, such as 310 or 240, before you open anything.

Which NEC calculations can I practice?

Ampacity derating, overcurrent sizing, conduit fill, box fill, voltage drop, equipment and electrode grounding conductors, motor circuits and the dwelling service calculation. Problems are generated, so you can practice without seeing the same question twice.

Are there free NEC conduit fill and voltage drop calculators?

Yes. Eight field calculators are free: ampacity, conduit fill, box fill, voltage drop, grounding conductors, motor circuits, dwelling load and Ohm's law. They are study estimates with stated assumptions, not a substitute for the code book.
