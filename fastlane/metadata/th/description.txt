เฉพาะประมวลกฎไฟฟ้าของสหรัฐอเมริกาเท่านั้น
ค่าทุกค่าในแอปนี้มาจาก National Electrical Code 2023 ซึ่งเป็นมาตรฐานที่ใช้ในสหรัฐอเมริกา ไม่ใช่สื่อการเรียนสำหรับกฎการเดินสายของประเทศอื่น และตัวแอปเป็นภาษาอังกฤษ

การสอบช่างไฟฟ้าของสหรัฐฯ เปิดหนังสือได้ ซึ่งช่วยได้น้อยกว่าที่ฟังดู เพราะมีการจับเวลา และทุกข้อที่คุณต้องเปิดหา ทำให้คุณเสียอีกสองข้อที่ไปไม่ถึง

หาให้เจอเร็ว
อ่านสถานการณ์แล้วบอกหมายเลขข้อกำหนดก่อนเปิดอะไรทั้งสิ้น Article 310 หรือ Article 240 แบบฝึกนี้เองที่ช่วยประหยัดเวลาหลายนาทีในวันสอบ

การคำนวณที่ทำให้คนสอบตก
พิกัดกระแสและตัวคูณปรับค่า การเลือกขนาดเครื่องป้องกัน อัตราการบรรจุในท่อร้อยสาย ปริมาตรกล่องต่อสาย แรงดันตก ตัวนำสำหรับต่อลงดิน วงจรมอเตอร์ และการคำนวณเมนของบ้านพักอาศัย โจทย์แต่ละข้อถูกสร้างขึ้นใหม่แทนที่จะวนซ้ำจากคลังข้อสอบตายตัว จึงฝึกได้นานเท่าที่ต้องการโดยไม่เจอโจทย์เดิมซ้ำ

ตัวเลือกผิดที่สอนคุณได้
ตัวเลือกที่ผิดทุกข้อคือตัวเลขที่ได้จากความผิดพลาดแบบหนึ่งที่พบบ่อย เมื่อเลือกแล้วคุณจะรู้ว่าพลาดตรงไหน ไม่ใช่แค่รู้ว่าตอบผิด

แสดงวิธีทำ
ถ้าคำนวณพลาด คุณจะได้ขั้นตอนที่มีลำดับเลข ไม่ใช่ย่อหน้ายาว ๆ แทบไม่มีใครสอบตกเพราะเลขคณิต แต่ตกเพราะข้ามไปหนึ่งขั้นตอน

อะไรใช้ได้ฟรี
Code Basics, Conductors and Ampacity และ Installation Rules พร้อมเครื่องคำนวณหน้างานครบทั้งแปดตัว ได้แก่ พิกัดกระแส อัตราการบรรจุในท่อ ปริมาตรกล่อง แรงดันตก ตัวนำต่อลงดิน วงจรมอเตอร์ โหลดบ้านพักอาศัย และกฎของโอห์ม

ELECTRICIAN+
ปลดล็อก Worked Calculations, Service and Load Calc และ Grounding and Motors พร้อมชุดโจทย์เพิ่มในทุกส่วน แบบฝึกที่สร้างขึ้นไม่จำกัด การทดสอบจับเวลา และ Code Minute
