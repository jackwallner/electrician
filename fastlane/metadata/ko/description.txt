미국 전기 규정만 다룹니다
이 앱의 모든 수치는 미국에서 사용하는 표준인 National Electrical Code 2023에서 나옵니다. 한국전기설비규정을 비롯한 다른 나라의 배선 규정 학습용이 아니며, 앱 화면은 영어입니다.

미국 전기기사 시험은 책을 펴 놓고 봅니다. 들리는 것만큼 여유롭지는 않습니다. 시간 제한이 있고, 찾아봐야 하는 문제 하나마다 끝내 손대지 못할 문제가 두 개씩 늘어납니다.

빨리 찾기
상황을 읽고, 무엇이든 펼치기 전에 조항을 말합니다. Article 310인지 Article 240인지. 시험 당일 몇 분을 아껴 주는 훈련이 바로 이것입니다.

사람을 떨어뜨리는 계산
허용 전류와 보정 계수, 과전류 보호 선정, 전선관 점유율, 박스 용적, 전압 강하, 접지 도체, 전동기 회로, 그리고 주택 인입 계산. 각 문제는 고정된 문제 은행에서 반복되는 대신 생성되므로, 원하는 만큼 연습해도 같은 문제를 두 번 만나지 않습니다.

가르쳐 주는 오답
오답 보기는 모두 특정한 흔한 실수가 만들어 내는 바로 그 숫자입니다. 하나를 고르면 틀렸다는 사실만이 아니라 어떤 실수를 했는지 알게 됩니다.

풀이 과정 보기
계산을 틀리면 문단이 아니라 번호가 매겨진 단계가 나옵니다. 산수 때문에 떨어지는 사람은 거의 없습니다. 건너뛴 한 단계 때문에 떨어집니다.

무료로 쓸 수 있는 것
Code Basics, Conductors and Ampacity, Installation Rules와 여덟 개의 현장 계산기 전부: 허용 전류, 전선관 점유율, 박스 용적, 전압 강하, 접지 도체, 전동기 회로, 주택 부하, 옴의 법칙.

ELECTRICIAN+
Worked Calculations, Service and Load Calc, Grounding and Motors를 열고, 각 섹션의 추가 문제 세트, 무제한 생성 연습, 시간 제한 챌린지, Code Minute를 제공합니다.
