## What survived, ranked by users reached times cost

1. **B1**: weekly notification to former members that opens the paywall and cannot be turned off in the app. Hits lapsed members who stopped opening the app more than 3 days before their first post-lapse launch.
2. **B2**: onboarding card promises "we will schedule it" and never does; stays visible after a later grant.
3. **B3**: Undo leaves a phantom miss in accuracy and readiness (stats only, not the review queue).
4. **B4**: Exam Target Cancel keeps edits; toggling the date off and cancelling loses the date.
5. **B7**: `converted_with_trial` true for trial-ineligible buyers (analytics only).

The audit ranked B3 second and B5 third. B5 is unproven and B3's cost is stats-only once the review-queue claim falls, so B2 moves up.

## Method changes that would have prevented the errors

1. **Check every cited path and symbol exists before publishing.** A script that greps each `file:line` and backticked identifier in the report against the repo would have caught M1 to M11, which came from another project's audit.
2. **Model third-party launch behaviour from its source, not from a seam.** B1's test drives `setLocalOverride` and never shows `isPro` true at launch. Real RevenueCat replays cached `CustomerInfo` on delegate set and honours it for 3 days, which decides whether the bug occurs at all. Read the SDK before writing a launch-state test.
3. **Follow a recorded value to the screen that consumes it.** B3's Fix My Mistakes claim stopped at `needsReview` and missed the documented `unreviewableItemIDs` filter one function later (`PracticeRecordStore.swift:241-251`).
4. **Render the route, step by step.** B2's "tap No reminders" is a no-op because the row is already selected after denial; B5 cited a view whose date is computed. Writing down what each screen shows after each tap would have caught both.
5. **Separate app state from OS delivery.** B6 counted a user's own iOS-level choice as an app state bug.
6. **Make repro tests assert the broken promise, not a preferred fix.** B2's test asserts the flag clears on "No reminders" and B3's asserts `needsReview`; neither is what the user sees. Label opinion tests as such.
7. **Give impact claims a basis.** "A large share" (B2) and "common" (B5) had none.
